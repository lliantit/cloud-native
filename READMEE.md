# Лабораторна робота №4
## Побудова багаторівневої архітектури серверного застосунку

**Дисципліна:** Cloud-native системи  
**Виконав:** Михалюк Ілля

### Опис
У цій лабораторній роботі реалізовано два еквівалентних сервери (Node.js та Go) з використанням багаторівневої архітектури. Головна мета - усунення жорсткої залежності бізнес-логіки від HTTP-фреймворків та конкретних реалізацій баз даних.

### Архітектурні шари
Проєкти розділені на ізольовані рівні:
- **Router:** визначення HTTP-ендпойнтів, методів та підключення middleware.
- **Controller:** прийом запитів, базова валідація, виклик відповідного методу Service та перетворення помилок у HTTP-статуси.
- **Service:** чиста бізнес-логіка. Працює з абстракцією доступу до даних (через інтерфейс у Go та ін'єкцію залежностей у Node.js).
- **Repository:** інкапсуляція роботи зі сховищем даних (наразі реалізовано `InMemoryUserRepository`).

### Реалізований функціонал
- Повний CRUD для користувачів (`GET`, `POST`, `PUT`, `DELETE`).
- Централізований механізм обробки помилок (відповіді 400, 404, 409, 500).
- **Middleware 1:** Request Logging (фіксація методу, шляху, статусу та тривалості запиту).
- **Middleware 2:** Request Validation (перевірка типів та обов'язкових полів).
- Покриття тестами: Unit-тести для Service та Integration-тести для API (через Jest/Supertest для Node.js та `httptest` для Go).
